## Bug Details

### 1. Timer `Size` `DragValue` does not commit on `Enter` (A1.1)
- **Where:** `crates/ui-egui/src/properties.rs:5461-5469`
- **Trigger:** Select a `Timer` object, click the `Size` `DragValue` in the Format tab, type `"40"`, and press `Enter`.
- **Effect:** `Timer.style.size` stays at `24.0` instead of updating to `40.0` because `r.drag_stopped() || r.lost_focus()` omits `enter` and lacks a `text_size_seen` guard.
- **Suggested fix:** Use the same `enter` + `text_size_seen` commit pattern used by `show_text_controls`.

### 2. Multi-select `Size` field does not commit on blur / click-away (A1.4)
- **Where:** `crates/ui-egui/src/properties.rs:2363-2403`
- **Trigger:** Multi-select two `Text` objects with different sizes, type `"36"` into the `Size` field, and click away onto the panel header without pressing `Enter`.
- **Effect:** Neither text box updates on blur (`t1` remains `20.0`).
- **Suggested fix:** Preserve the edited `props.multi_text_size` buffer across frames while focused so `r.lost_focus()` sees the typed string before per-frame sync resets it.

### 3. Inline edit loses partial substring selection when inspector `Font size` takes focus (A1.5)
- **Where:** `crates/ui-egui/src/canvas.rs` / `crates/ui-egui/src/properties.rs`
- **Trigger:** Open inline edit on `"Hello World"`, select `"World"` (`6..11`), then click `Font size` in the inspector and type `"40"` + `Enter`.
- **Effect:** The entire `"Hello World"` string receives `size: Some(40.0)` instead of only `"World"`.
- **Suggested fix:** Snapshot the active inline-edit selection range before focus leaves the canvas `TextEdit`, or apply `text.style_range` using the stored `inline_edit` range.

### 4. Custom line-spacing `DragValue` inside `ComboBox` popup drops `Enter`/blur commit (A1.6)
- **Where:** `crates/ui-egui/src/properties.rs:3822-3861`
- **Trigger:** Open the paragraph `Spacing` combo box, type `"1.85"` into the `custom` `DragValue`, and press `Enter` (or click outside).
- **Effect:** The popup closes on the same frame and `line_spacing` remains at its previous value (`1.5`).
- **Suggested fix:** Commit `chosen = Some(...)` on `r.has_focus() && enter` or `r.lost_focus()` before egui closes the `ComboBox` popup.

### 5. Hard-step gradient (two stops at `0.5`) blurs across mesh triangles (A2.4)
- **Where:** `crates/render/src/shape_fill.rs` / `crates/render/src/paint.rs:193`
- **Trigger:** Render a wide rectangle with stops `#FF0000 @ 0.0`, `#FF0000 @ 0.5`, `#0000FF @ 0.5`, `#0000FF @ 1.0`.
- **Effect:** Pixels just past `50%` (`x=510` on `x=100..900`) sample `[84, 0, 171]` (purple blend) instead of pure blue because mesh triangles straddle `0.5`.
- **Suggested fix:** Split gradient mesh subdivision edges at stop positions (especially duplicate/tied stop positions).

### 6. `Hover` state with solid fill override does not mask 3-stop gradient in `render_player_rgba` (A2.7)
- **Where:** `crates/render/src/compose.rs:1239-1243` / `crates/logic/src/`
- **Trigger:** Send `Input::HoverStart { object: "b1" }` to a `Player` whose button has a 3-stop gradient and a `"hover"` state with `fill: "#11AA11"`, then call `render_player_rgba`.
- **Effect:** Yellow pixels from the Normal 3-stop gradient are still rendered.
- **Suggested fix:** Ensure `Player::handle(&Input::HoverStart)` activates the `"hover"` state override or `compose` checks `player.is_hovered` when resolving `state_fill`.

### 7. Format Painter (`apply_look`) does not copy gradient `fill_style` onto closed `ObjectKind::Path` (A2.8)
- **Where:** `crates/engine/src/commands.rs:5624-5720`
- **Trigger:** Arm `Paint` on a shape with a 4-stop linear gradient and click a closed `ObjectKind::Path`.
- **Effect:** `p1.path.fill_style` remains `None`.
- **Suggested fix:** Extend `apply_look` to copy `fill`, `fill_style`, and `outline` onto `ObjectKind::Path` when `path.closed` is `true`.

### 8. `Spacebar` toggles timeline playback while inline text edit is focused (A4.10)
- **Where:** `crates/ui-egui/src/shortcuts.rs` / `crates/ui-egui/src/timeline.rs`
- **Trigger:** Double-click a text object to open inline text edit, then press `Key::Space`.
- **Effect:** `timeline_playback.is_playing()` becomes `true` while the user is typing text.
- **Suggested fix:** Guard the Spacebar play/pause shortcut with `!ctx.wants_keyboard_input() && editor.ui.inline_edit.is_none()`.

### 9. `Shapes` gallery reopens at shrunk 1-row height after filtering before close (A6.3)
- **Where:** `crates/ui-egui/src/shape_gallery.rs:309`
- **Trigger:** Open `Shapes` dialog, type `"Heart"` in search (shrinking to 1 row), click `Heart` to close, then reopen `Shapes`.
- **Effect:** The reopened `Shapes` window stays at the shrunk height (`168.2px < 200.0px`).
- **Suggested fix:** Clear `shape_gallery_query` on close or set `.default_height(...)` / `.min_height(...)` on `Dialog::new("Shapes")`.

### 10. `.github/workflows/release.yml` has `continue-on-error: true` on `Build Windows installer` (A8.4)
- **Where:** `.github/workflows/release.yml:53`
- **Trigger:** Any failure in `choco install innosetup` or `ISCC.exe` during a release tag build.
- **Effect:** The Windows release job still succeeds and publishes only `-portable.exe` without `-setup.exe`.
- **Suggested fix:** Remove `continue-on-error: true` from the `Build Windows installer` step.

### 11. `BaseSlideView::Dim` does not dim base slide when `dim_other_layers` is `false` (A9.1)
- **Where:** `crates/ui-egui/src/canvas.rs:5463-5466`
- **Trigger:** Uncheck `dim_other_layers` in the Layers panel, then explicitly click `Dim` in the `Base slide: Show | Dim | Hide` bar.
- **Effect:** `dim_base` evaluates to `false` and base objects remain at full alpha (`255`).
- **Suggested fix:** Remove `&& editor.ui.layers.dim_other_layers` from `dim_base` when `base_slide_view == BaseSlideView::Dim`.

### 12. `BaseSlideView::Hide` does not hide Master slide objects while editing a layer (A9.3)
- **Where:** `crates/ui-egui/src/canvas.rs:5478`
- **Trigger:** Assign a master slide with `"Master Footer"` to a slide, switch to a layer, and click `Hide` in `Base slide:`.
- **Effect:** `"Master Footer"` remains painted on the canvas.
- **Suggested fix:** Include master slide items in `is_base_slide_item` when `BaseSlideView::Hide` (or `Dim`) is active.

### 13. `Base slide: Show | Dim | Hide` toggle clips off central panel at `1024×680` with 6 layers (A9.9)
- **Where:** `crates/ui-egui/src/canvas.rs:1507`
- **Trigger:** Add 6 named layers on a `1024×680` window and select the 6th layer.
- **Effect:** The `Show` / `Dim` / `Hide` pills are pushed past the right edge of `central_panel_rect()`.
- **Suggested fix:** Use wrapping (`horizontal_wrapped`) or a scrollable layer-pill strip with the `Base slide:` toggle pinned on the right.

### 14. Right-panel Question editor clips widgets horizontally (`1351 > 1280`) (A10.1)
- **Where:** `crates/ui-egui/src/question.rs`
- **Trigger:** Open a `multiple_choice` question slide in the right panel at `1280×900` (`PROPERTIES_PANEL_WIDTH`).
- **Effect:** `layout_report` reports `clipped-widget` findings where boxes extend to `x=1351` past the `x=1280` panel edge.
- **Suggested fix:** Constrain choice row widths and inner widgets to `ui.available_width()` inside `show_question_editor_body`.

### 15. Selecting an MC answer/prompt object does not show Question section in right panel (A10.4)
- **Where:** `crates/ui-egui/src/question.rs:331-353`
- **Trigger:** On a Multiple Choice question slide (`s-quiz`), select the prompt or a choice object instead of `btn-submit`.
- **Effect:** `is_question_object` returns `false` and the right panel hides the `Question` section.
- **Suggested fix:** Return `true` in `is_question_object` for any object on a slide with `slide.question.is_some()` (or objects referenced by `SelectChoice` / question prompt).

### 16. Clicking empty canvas while non-sticky Format Painter is armed does not disarm it (A11.5)
- **Where:** `crates/ui-egui/src/canvas.rs:5655-5665`
- **Trigger:** Arm non-sticky `Paint` on an object, then click empty canvas space.
- **Effect:** `editor.ui.format_painter` remains `Some(...)` instead of disarming.
- **Suggested fix:** Disarm `editor.ui.format_painter = None` on empty-canvas click when `!sticky`.

### 17. Editor shortcuts (`Delete`, `Cmd+M`, `Cmd+Z`) mutate the course while Preview modal is open (A12.9)
- **Where:** `crates/ui-egui/src/shortcuts.rs` / `crates/ui-egui/src/lib.rs`
- **Trigger:** Select an object, open Preview, and press `Delete`, `Cmd+M`, `Cmd+Z`.
- **Effect:** `editor.session.revision` increments from `0` to `3` behind the Preview modal.
- **Suggested fix:** Short-circuit all editor keyboard shortcuts whenever `editor.preview.is_some()`.

### 18. Decorative non-placeholder shapes on `slideMaster1.xml` are not inherited onto slides (A13.5)
- **Where:** `crates/pptx/src/lib.rs`
- **Trigger:** Import a `.pptx` whose `slideMaster1.xml` contains a non-placeholder decorative shape in `<p:spTree>`.
- **Effect:** The decorative master shape is missing from the imported slide/master.
- **Suggested fix:** Import non-placeholder shapes from `slideMaster*.xml` onto the corresponding CourseCraft master or slide background layer.

### 19. Non-16:9 PPTX slide sizes (`4:3`, `9:16`) are hardcoded to `16:9` (`1.7778`) on import (A13.7)
- **Where:** `crates/pptx/src/lib.rs`
- **Trigger:** Import a `4:3` (`9144000×6858000`) or `9:16` (`5143500×9144000`) `.pptx`.
- **Effect:** `course.slide_size` stays `1280×720` (`ratio = 1.7778`), distorting aspect ratios.
- **Suggested fix:** Derive `course.slide_size` from `<p:sldSz cx="..." cy="..."/>` in `ppt/presentation.xml`.

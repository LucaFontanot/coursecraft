# M31 Bug-Hunt Log — 2026-11-23

## S1 — File shortcuts (`Ctrl/Cmd+S`, `Shift+S`, `O`, `N`), menu hints, shortcuts dialog, and request guards

- **Changed:**
  - `crates/ui-egui/src/lib.rs`: Hoisted `requests` above the shortcut section in `Editor::show` and bound `Ctrl+Shift+S` (before `Ctrl+S`), `Ctrl+S`, `Ctrl+O`, and `Ctrl+N` via `menu::parse_shortcut` under `!preview_has_focus && !ui.ctx().egui_wants_keyboard_input() && self.ui.inline_edit.is_none()` + modal/crop/publish-busy guards, gating `Save`/`SaveAs` on `self.file_ops_available && !self.ui.show_welcome` and `Open` on `self.file_ops_available`.
  - `crates/ui-egui/src/menu.rs`: Added `.shortcut_text(shortcut_label(ui.ctx(), ...))` to File menu items `New`, `Open…`, `Save`, and `Save As…`; updated `format_shortcut` to split `" / "`-separated compound shortcuts so every segment formats with native macOS glyphs.
  - `crates/ui-egui/src/shortcuts.rs`: Added a `File` group at the top of `build_shortcut_groups()` (`New / Open`, `Save / Save As`, `Publish course`) and removed the duplicate `Publish course` row from `General`.
  - `apps/coursecraft/src/main.rs` & `apps/coursecraft/Cargo.toml`: Added `has_blocking_modal()` in desktop `EditorApp` to ignore `New`/`Open`/`Save`/`SaveAs` while `pending_action`, `conflict_prompt`, `restore_prompt`, or `error_modal` is active. On `wasm32`, installed a `window` `keydown` listener (`install_web_file_shortcut_guard` / `should_prevent_browser_file_shortcut`) calling `prevent_default()` for `Ctrl/Cmd+S`, `Ctrl/Cmd+Shift+S`, `Ctrl/Cmd+O`, and `Ctrl/Cmd+N` only (note: `eframe` 0.37.0 already prevents default for `S`/`O` when the canvas is focused, but not `N`; the `window` guard covers `N` and unfocused-canvas cases while leaving text-field keys untouched).
- **Tests:** Added `m31_01_file_shortcuts_emit_requests_and_shift_s_beats_s`, `m31_02_file_shortcuts_suppressed_in_text_edit_inline_preview_and_welcome`, `m31_04_file_menu_hints_and_compound_shortcut_formatting` in `crates/ui-egui/src/tests.rs`, and `m31_03_desktop_file_shortcuts_route_dirty_prompts_and_block_during_modals` in `apps/coursecraft/src/u16_shell_tests.rs`.

## S1b — `ResizeMode` (`Scale`, `Fill`, `Keep`), `"fill"` mode, docs, and tests

### Implemented
- `crates/engine/src/slide_size.rs`:
  - Replaced `scale: bool` with `pub(crate) enum ResizeMode { Scale, Fill, Keep }`.
  - `ResizeMode::Fill` uses `factor = (w / old_w).max(h / old_h)` and centres `(dx, dy)` symmetrically; `ResizeMode::Keep` leaves content untouched.
- `crates/engine/src/commands.rs`:
  - Accepted `"mode": "fill"` in `course_set_slide_size` alongside `"scale"` and `"keep"`, and updated the `REGISTRY` params string.
- `docs/cli.md` & `docs/spec/course-model.md`:
  - Updated `course.set_slide_size` params in `docs/cli.md` to `"mode": "scale"|"fill"|"keep"`.
  - Documented `slide_size` bounds (`100..=7680` × `100..=4320`) and `"scale"` / `"fill"` / `"keep"` resize modes in `docs/spec/course-model.md`.
- `crates/engine/src/tests.rs` & `crates/engine/src/m27_all_commands_undo_tests.rs`:
  - Added `set_slide_size_fill_uses_max_factor_and_centres_overhang` (`A-01`).
  - Added `"fill"` coverage to `A-02` (`set_slide_size_scale_scales_states_and_state_extras`), `A-03` (`set_slide_size_scale_scales_previously_missed_base_fields`), `A-04` (`set_slide_size_extreme_aspects_and_clamps_stay_valid`), and `FZ-01` (`panic_hunt`).
  - Added `set_slide_size_fill_undo_redo_and_cli_docs_sync` (`A-05`) in `m27_all_commands_undo_tests.rs`.

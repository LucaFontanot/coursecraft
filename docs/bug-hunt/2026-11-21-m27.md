  - **BUG-A3** (`crates/lms/src/bridge.rs`): Added `LOCATION_LIMIT_12 = 255` for SCORM 1.2 `cmi.core.lesson_location` so oversized slide IDs are skipped with a warning.

  - **BUG-A6** (`crates/lms/src/bridge.rs`): Treated empty initial status `""` as first launch in `is_first_launch` for both SCORM 1.2 and SCORM 2004.
  - **BUG-A7** (`crates/publish/src/lib.rs`, `crates/scorm/src/lib.rs`): Stopped listing `imsmanifest.xml` inside `<resource>` in `build_package_standard_with_folders`, and enforced XML `NCName` start character (`[A-Za-z_]`) in `valid_identifier`.

  - **BUG-A10** (`crates/xapi/src/launch.rs`, `crates/lms/src/lrs.rs`): Rejected hostless `"http://"` / `"https://"` URLs in `is_http_url` / `normalize_endpoint`, and rejected empty/whitespace `"auth-token"` in `XapiBridge::handle_fetch`.
  - **BUG-B3** (`crates/publish/src/lib.rs`): Added `Video.poster` and `Path.fill_style.picture_src()` to `collect_object_media`.
